# المرحلة 7: ربط كل الأجزاء ببعض

## الأولوية: 🟡 متوسطة

## السياق
حالياً الوحدات تعمل بشكل منفصل. الهدف هو ربطها في نظام ERP متكامل حيث كل عملية تؤثر على باقي الوحدات.

## المهام

### 7.1 ربط POS بالمخزون
**الملفات:** `pos_screen.dart` + `database_helper.dart`

عند إتمام عملية بيع في POS:
- [ ] خصم الكمية المباعة من `products.quantity`
- [ ] إنشاء سجل في `inventory_transactions` (نوع: sale)
- [ ] تحديث `cost_of_goods_sold` في حساب المصروفات
- [ ] تنبيه إذا الكمية أقل من `min_quantity`
- [ ] منع البيع إذا الكمية = 0 (مع خيار Override)

### 7.2 ربط الفواتير بالمخزون
**الملفات:** `invoice_entry_screen.dart` + `accounting_engine.dart`

عند إنشاء فاتورة مبيعات:
- [ ] خصم الأصناف المباعة من المخزون
- [ ] حساب تكلفة البضاعة المباعة (COGS)
- [ ] إنشاء 3 قيود:
  1. مدين: المدينين/النقد | دائن: الإيرادات (بقيمة البيع)
  2. مدين: تكلفة البضاعة | دائن: المخزون (بالتكلفة)
  3. مدين: المدينين/النقد | دائن: ضريبة مبيعات (بالضريبة)

عند إنشاء فاتورة مشتريات:
- [ ] إضافة الأصناف للمخزون
- [ ] تحديث تكلفة الشراء (المتوسط المرجح أو FIFO)
- [ ] إنشاء قيد: مدين المخروزون + ضريبة مشتريات | دائن الدائنين

### 7.3 ربط الرواتب بالمحاسبة
**الملفات:** `payroll_service.dart` + `accounting_engine.dart`

عند معالجة الرواتب الشهرية:
- [ ] إنشاء قيد شامل:
  - مدين: مصروف رواتب (حسب مركز التكلفة لكل موظف)
  - مدين: مصروف بدل سكن
  - مدين: مصروف بدل مواصلات
  - دائن: رواتب مستحقة (إجمالي الصافي)
  - دائن: تأمينات مستحقة (حصة الموظف)
  - دائن: ضريبة دخل مستحقة (إن وجدت)
- [ ] ربط كل موظف بمركز تكلفة ← تظهر في تقرير مركز التكلفة
- [ ] خصم أقساط السلف تلقائياً مع تحديث رصيد السلفة

### 7.4 ربط العهد بالمحاسبة
**الملفات:** `custody_service.dart` + `accounting_engine.dart`

عند صرف عهدة مالية:
- [ ] قيد: مدين عهد لدى الموظف X | دائن الخزينة/البنك
عند تصفية العهدة:
- [ ] قيد: مدين مصروفات (حسب الفئة) | دائن عهد لدى الموظف X
- [ ] إذا هناك فرق (مرتجع): مدين الخزينة | دائن عهد لدى الموظف

### 7.5 ربط الأصول بالمحاسبة
**الملفات:** `asset_service.dart` + `depreciation_service.dart`

- [ ] إهلاك شهري تلقائي:
  - قيد: مدين مصروف إهلاك | دائن مجمع الإهلاك
- [ ] عند استبعاد أصل:
  - قيد: مدين مجمع الإهلاك + مدين خسارة (أو دائن ربح) | دائن الأصل

### 7.6 ربط الشيكات بالمحاسبة
**ملف:** `cheque_service.dart`

عند استلام شيك:
- [ ] قيد: مدين أوراق قبض | دائن المدينين
عند تحصيل الشيك:
- [ ] قيد: مدين البنك | دائن أوراق قبض
عند ارتجاع الشيك:
- [ ] قيد عكسي + تنبيه

### 7.7 ربط المشاريع بالتكاليف
**ملف:** `projects_screen.dart`

- [ ] كل فاتورة/مصروف/رواتب مربوطة بمشروع → تظهر في تقرير المشروع
- [ ] حساب ربح/خسارة المشروع = إيرادات المشروع - تكاليف المشروع
- [ ] عرض نسبة الإنجاز vs الميزانية

### 7.8 ربط AI ببيانات حقيقية
**ملف:** `ai_service.dart` + `ai_chat_controller.dart`

- [ ] عند السؤال عن رصيد → قراءة من DB حقيقي
- [ ] عند السؤال عن فواتير معلقة → query فعلي
- [ ] عند السؤال عن موظف → بيانات حقيقية
- [ ] System Prompt يتضمن: اسم الشركة، العملة، عدد الموظفين، إجمالي المبيعات

## معايير القبول
- [ ] بيع في POS → المخزون ينقص تلقائياً
- [ ] فاتورة مبيعات → 3 قيود يومية تنشأ تلقائياً
- [ ] معالجة رواتب → قيد يومية مع مراكز تكلفة
- [ ] صرف عهدة → قيد يومية تلقائي
- [ ] إهلاك أصل → قيد شهري تلقائي
- [ ] AI يقدر يقول "رصيد الخزينة 50,000" من بيانات حقيقية
