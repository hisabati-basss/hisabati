# المرحلة 9: التقارير والطباعة

## الأولوية: 🟡 متوسطة

## السياق
خدمة PDF حالياً تدعم إنشاء فواتير أساسية. التطبيق يحتاج مجموعة تقارير محاسبية كاملة بجودة QuickBooks.

## المهام

### 9.1 قوالب PDF احترافية
**ملف:** `lib/services/pdf_service.dart`

#### أ. فاتورة ضريبية (ZATCA-compliant)
- [ ] شعار الشركة في الأعلى
- [ ] بيانات الشركة (اسم، عنوان، رقم ضريبي)
- [ ] بيانات العميل
- [ ] جدول الأصناف مع: الوصف، الكمية، السعر، الضريبة، الإجمالي
- [ ] ملخص: المجموع الفرعي، الضريبة، الإجمالي
- [ ] QR Code (ZATCA TLV format) للسعودية
- [ ] المبلغ بالكتابة (تفقيط)
- [ ] توقيع رقمي / ختم
- [ ] رقم الفاتورة وتاريخها

#### ب. عرض سعر (Quotation PDF)
- [ ] نفس تصميم الفاتورة مع تعديلات:
  - عنوان "عرض سعر" بدلاً من "فاتورة"
  - تاريخ الصلاحية
  - الشروط والأحكام

#### ج. سند قبض / صرف
- [ ] تصميم مختصر: المبلغ، المستلم/المُصرف له، التاريخ، الطريقة
- [ ] المبلغ بالكتابة

#### د. كشف حساب (Statement of Account)
- [ ] بيانات العميل/المورد
- [ ] جدول: التاريخ | الوصف | المدين | الدائن | الرصيد
- [ ] رصيد افتتاحي وختامي

#### هـ. مسير رواتب (Payslip)
- [ ] بيانات الموظف
- [ ] تفصيل: الراتب الأساسي، البدلات، الإضافي
- [ ] الاستقطاعات: تأمينات، غياب، سلف
- [ ] صافي الراتب
- [ ] لغتين (عربي/إنجليزي)

#### و. تقارير محاسبية
- [ ] ميزان المراجعة (Trial Balance)
- [ ] قائمة الدخل (Profit & Loss)
- [ ] الميزانية العمومية (Balance Sheet)
- [ ] تقرير أعمار الديون (Aging Report)
- [ ] تقرير التدفق النقدي (Cash Flow Statement)
- [ ] تقرير مركز التكلفة (Cost Center Report)

### 9.2 تحسين شاشة التقارير
**ملف:** `lib/screens/financial_reports_screen.dart`

- [ ] تقسيم التقارير إلى فئات:
  - 📊 تقارير أساسية (ميزان، دخل، ميزانية)
  - 💰 تقارير مالية (تدفق نقدي، أعمار ديون)
  - 👥 تقارير HR (مسيرات، حضور)
  - 📦 تقارير مخزون (تقييم، حركة)
  - 📈 تقارير إدارية (KPIs، مقارنات)

- [ ] لكل تقرير:
  - عرض تفاعلي في الشاشة (جداول + رسوم بيانية)
  - زر "تصدير PDF"
  - زر "تصدير Excel" (CSV)
  - فلتر بالتاريخ (من - إلى)

### 9.3 تصدير Excel/CSV
**ملف جديد:** `lib/services/export_service.dart`
- [ ] تصدير أي جدول كـ CSV
- [ ] تنسيق الأرقام والتواريخ حسب اللغة
- [ ] دعم Unicode (للعربية)
- [ ] فتح الملف تلقائياً بعد التصدير

### 9.4 مقارنة الفترات
- [ ] مقارنة هذا الشهر vs الشهر الماضي (نسبة التغيير)
- [ ] مقارنة هذا الربع vs الربع السابق
- [ ] مقارنة هذه السنة vs السنة السابقة
- [ ] رسم بياني timeline للمقارنة

### 9.5 لوحة KPIs سريعة
في أعلى شاشة التقارير:
- [ ] إجمالي المبيعات (الفترة)
- [ ] إجمالي المشتريات (الفترة)
- [ ] صافي الربح
- [ ] معدل التحصيل (المدفوعة / الإجمالي)
- [ ] أكبر عميل مدين
- [ ] أكبر مورد دائن

## معايير القبول
- [ ] كل PDF يفتح بشكل صحيح ويطبع بجودة عالية
- [ ] الفاتورة تحتوي QR Code صالح (ZATCA TLV)
- [ ] ميزان المراجعة: مجموع المدين = مجموع الدائن
- [ ] تصدير CSV يفتح في Excel بشكل صحيح مع الأعمدة العربية
- [ ] كل تقرير يدعم فلتر التاريخ
