## المهام

### 4.1 توسيع محرك المحاسبة
**ملف:** `lib/core/accounting/accounting_engine.dart`

#### أ. دورة المبيعات الكاملة
```
عرض سعر (Quotation) 
  → [موافقة العميل] 
    → فاتورة مبيعات (Invoice)
      → [دفع نقدي] → سند قبض (Receipt Voucher) → قيد: مدين الخزينة / دائن المدينين
      → [دفع آجل] → تحديث المدينين → متابعة أعمار الديون
      → [دفع بنكي] → سند قبض → قيد: مدين البنك / دائن المدينين
```

- [ ] `processQuotation()` - إنشاء عرض سعر
- [ ] `convertQuotationToInvoice(quotationId)` - تحويل عرض سعر لفاتورة
- [ ] `processReceiptVoucher()` - تسجيل سند قبض مع قيد يومية تلقائي
- [ ] `processCreditNote()` - إشعار دائن (مرتجع مبيعات) مع قيد عكسي

#### ب. دورة المشتريات الكاملة
```
أمر شراء (Purchase Order)
  → [استلام البضاعة]
    → فاتورة مشتريات (Purchase Invoice)
      → [دفع] → سند صرف (Payment Voucher) → قيد: مدين الدائنين / دائن البنك
```

- [ ] `processPurchaseOrder()` - أمر شراء
- [ ] `processPaymentVoucher()` - سند صرف مع قيد يومية تلقائي
- [ ] `processDebitNote()` - إشعار مدين (مرتجع مشتريات)

#### ج. القيود المتقدمة
- [ ] `processRecurringTransaction()` - معالجة المعاملات المتكررة
- [ ] `closeFiscalPeriod(startDate, endDate)` - إقفال فترة مالية
- [ ] `closeFiscalYear(yearId)` - إقفال سنة مالية مع ترحيل الأرصدة
- [ ] `generateAgingReport(type)` - تقرير أعمار الديون (مدينين/دائنين)
