# 🏛️ دستور مشروع حساباتي ERP (Hisabati Constitution)

## الهوية
- **الاسم:** حساباتي ERP (Hisabati)
- **النوع:** نظام إدارة موارد المؤسسات (ERP) 
- **المنصة:** Flutter (Desktop أولاً، ثم Mobile + Web)
- **قاعدة البيانات:** SQLite (أوفلاين) + Supabase (سحابي للمزامنة)
- **الذكاء الاصطناعي:** Gemini API (HBASSS Agent)
- **الهدف:** منافسة QuickBooks و Odoo

## المبادئ الأساسية (غير قابلة للتفاوض)

### 1. أوفلاين أولاً (Offline-First)
- كل شيء يعمل بدون إنترنت 100%
- المزامنة السحابية اختيارية وليست إجبارية
- قاعدة البيانات المحلية هي مصدر الحقيقة

### 2. القيد المزدوج (Double-Entry Accounting)
- كل عملية مالية تنشئ قيد يومية متوازن (مدين = دائن)
- لا يوجد تعامل مالي بدون قيد محاسبي
- شجرة الحسابات قابلة للتخصيص بالكامل

### 3. متعدد الدول والعملات
- دعم 20+ دولة عربية وأجنبية
- نسب ضريبية متغيرة حسب الدولة
- عملات متعددة مع تحويل تلقائي

### 4. الأمان
- لا مفاتيح API مكشوفة في الكود (كلها في .env)
- صلاحيات مستخدمين متعددة المستويات
- تشفير كلمات المرور بـ SHA-256 (crypto package)
- سجل تدقيق كامل (Audit Trail)
- **⛔ ممنوع منعاً باتاً: backdoors أو كلمات مرور ثابتة في الكود**

### 5. جودة الكود
- لا نصوص عربية مباشرة (كل شيء عبر tr() من easy_localization)
- كل شاشة تدعم Dark/Light mode
- كل شاشة تدعم RTL/LTR
- **كل زر يجب أن يكون فعال (لا onPressed فارغ ولا onTap: () {})**
- لا بيانات وهمية أو ثابتة — كل شيء من قاعدة البيانات
- لا deprecated APIs (withOpacity → withValues, RawKeyboardListener → KeyboardListener)

### 6. التصميم
- Apple-inspired glassmorphism
- ألوان: برتقالي #FF6B35 + ذهبي #F7C948
- خط Tajawal للعربية
- كل الشاشات responsive (Desktop + Tablet + Mobile)

## القواعد التقنية

### قاعدة البيانات
- إصدار حالي: **v72** (لا تزده إلا عند إضافة جدول/عمود)
- معرفات UUID لكل الجداول
- عمود `sync_status` INTEGER (0=not synced, 1=synced) في كل جدول
- عمود `updated_at` TEXT في كل جدول
- عمود `is_deleted` INTEGER DEFAULT 0 (soft delete) في كل جدول
- عمود `device_id` TEXT لتتبع الجهاز المصدر

### الخدمات
- كل خدمة Singleton pattern
- كل دالة async مع try-catch
- معالجة أخطاء واضحة باللغة العربية

### الشاشات
- كل شاشة StatefulWidget
- استخدام LayoutBuilder للتكيف
- الشاشات الكبيرة (>2000 سطر) يجب تقسيمها لـ widgets

### الذكاء الاصطناعي
- Function Calling لتنفيذ الأوامر
- System Prompt ديناميكي يتضمن بيانات الشركة
- Fallback محلي عند فقدان الاتصال
- TTS اختياري ويعمل على كل المنصات
